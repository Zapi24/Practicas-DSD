0. ACLARACIÓN IMPORTANTE: VERSIONES DE JAVA

Dependiendo de la versión de Java que utilice para evaluar la práctica, 
el uso de 'SecurityManager' (requerido en el guion) puede lanzar una 
excepción bloqueante en versiones modernas. 

Por este motivo, en las instrucciones de ejecución se proporcionan DOS 
versiones para cada comando:
[Opción A] Versión Estándar: Para versiones de Java antiguas.
[Opción B] Versión Moderna: Incluye el flag '-Djava.security.manager=allow' 
           para evitar bloqueos en versiones recientes de Java.


1. LIMPIEZA Y COMPILACIÓN (Opcional)

El proyecto ya se entrega compilado (archivos .class incluidos). A priori 
no es necesario recompilar. Sin embargo, si experimenta algún error o desea compilar desde cero, ejecute lo siguiente desde la raíz:

------------------------------------------------------------------------
cd Practica3_Donaciones/src
killall rmiregistry java
javac interfaces/*.java servidor/*.java cliente/*.java
------------------------------------------------------------------------


2. EJECUCIÓN DEL SISTEMA (Requiere 3 Terminales)

Para probar el sistema replicado, abra 3 terminales distintas y 
sitúese en todas ellas en la carpeta fuente del proyecto:

------------------------------------------------------------------------
cd Practica3_Donaciones/src
------------------------------------------------------------------------


- TERMINAL 1 (Desplegar Réplica 1)

------------------------------------------------------------------------------------------------------------------------------------------------
[Opción A - Java Antiguo]:
java -cp . -Djava.security.policy=servidor/server.policy servidor.LanzadorServidor 1099 Replica1 rmi://localhost:1100/Replica2

[Opción B - Java Moderno]:
java -Djava.security.manager=allow -cp . -Djava.security.policy=servidor/server.policy servidor.LanzadorServidor 1099 Replica1 rmi://localhost:1100/Replica2
------------------------------------------------------------------------------------------------------------------------------------------------
